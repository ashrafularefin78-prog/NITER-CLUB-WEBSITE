📋 Problem Statement

Why does NITER need a Clubs Portal?

📱

Fragmented Communication

Club activities scattered across Facebook, WhatsApp, Messenger, and word-of-mouth. No centralized platform.

📝

Manual Membership

Paper forms, Google Forms, no approval workflow. Students can't track their membership status.

🗓️

Event Chaos

No RSVP tracking, no capacity management, no attendance verification. Low event turnout.

🌐

No Digital Identity

Clubs depend on Facebook pages. When pages go down, the club's digital presence vanishes.

⏰

Admin Overhead

Hours spent manually collecting forms, sending reminders, and tracking applications.

🔍

Discovery Gap

New students have no easy way to learn about clubs, their activities, or how to get involved.

💡 Our Solution

A comprehensive web platform that centralizes and streamlines all club operations

🎓 For Students

  • 🔍 Discover & search all 11+ clubs
  • 📝 Apply via digital forms with tracking
  • 🤝 Join clubs with real-time status
  • 📅 RSVP to events & earn certificates
  • 📊 Personal dashboard with XP & badges

🛡️ For Club Executives

  • 📢 Publish notices with reactions
  • 📝 Build custom forms (visual builder)
  • ✅ Approve/reject with one click
  • 🗓️ Manage events, RSVPs & waitlists
  • 📣 Publish ads for events

👑 For Administrators

  • 👥 Role management & club assignments
  • 🔑 One admin per club system
  • 🛡️ Moderator approval workflow
  • 📋 Audit log for all actions
  • ⚙️ Site-wide settings control

🔐 Authentication & Roles

  • 👤 Visitor — Browse, fill forms, file complaints
  • 🎓 Member — Track submissions & memberships
  • 🛡️ Moderator — Manage club (admin approval required)
  • ⭐ Executive — Full club management access
  • 🔑 Club Admin — One per club, instant access
  • 👑 Global Admin — Everything, first account

📧 Email Notifications

  • 📬 Moderator Request — Admin notified on signup
  • 📬 Membership Submit — Club staff notified
  • 📬 Membership Decision — Student notified
  • 📬 Committee Edit — Moderators notified

All notifications use FormSubmit provider with configurable email addresses.

🔄 User Flows

🎓 Student Membership Flow

1. Browse Clubs

Student discovers clubs on the portal

2. Submit Form

Fills membership form with required fields

3. Auto-Create Request

System creates membership request (pending)

4. Email Notification

Club admin & moderators notified

5. Review & Decide

Admin approves or rejects the request

6. Student Notified

Email sent with decision

🛡️ Moderator Approval Flow

1. Student Signs Up

Selects "Club Moderator" + chooses club

2. Pending Request Created

ModeratorRequest document created

3. Email to Club Admin

Admin notified via /api/moderator-notify

4. Admin Reviews

Portal → Settings → Moderator requests

5. Approve/Reject

User role updated to "executive"

6. Portal Access

Moderator can now manage the club

🔒 Security Model

Firestore Rules

  • ✅ Public collections readable by anyone
  • ✅ Restricted collections scoped by club
  • ✅ Users can only update their own name
  • ✅ Admins can update roles and clubs
  • ✅ First-admin bootstrap marker
  • ✅ Role checks on every restricted read

Storage Rules

  • ✅ Submission photos under user uid folder
  • ✅ Guest submissions under guest/ folder
  • ✅ Image type validation (client-side)
  • ✅ File size limits (8 MB photos, 15 MB video)

Data Privacy

  • ✅ Student data never exposed publicly
  • ✅ Only club staff can read submissions
  • ✅ Passwords handled by Firebase Auth
