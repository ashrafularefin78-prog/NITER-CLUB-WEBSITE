02 / 12
The Challenge

Problem Statement

NITER's student clubs face critical operational challenges that reduce engagement and increase administrative burden.

📱 Fragmented Communication

Activities scattered across Facebook, WhatsApp, and word-of-mouth. No centralized platform for discovery.

📝 Manual Processes

Paper forms, Google Forms, no approval workflow. Students can't track their application status.

📅 Event Management

No RSVP tracking, no capacity management, no attendance verification. Low event turnout.

🌐 No Digital Identity

Clubs depend on Facebook. When pages go down, digital presence vanishes.

⏰ Administrative Overhead

Hours spent manually collecting forms, sending reminders, and tracking applications.

🔍 Discovery Gap

n

New students have no easy way to learn about clubs or how to get involved.

For Administrators

Workflows

User Flows

🎓 Student Membership

1
Browse Clubs
Student discovers clubs on the portal
2
Submit Form
Fills membership form with required fields
3
Auto-Create Request
System creates membership request (pending)
4
Email Notification
Club admin & moderators notified
5
Review & Decide
Admin approves or rejects the request
6
Student Notified
Email sent with decision

🛡️ Moderator Approval

1
Student Signs Up
Selects "Club Moderator" + chooses club
2
Pending Request
ModeratorRequest document created
3
Email to Admin
Admin notified via /api/moderator-notify
4
Admin Reviews
Portal → Settings → Moderator requests
5
Approve/Reject
User role updated to "executive"
6
Portal Access
Moderator can now manage the club

Protection

Security Model

Firestore Rules

  • ✓ Public collections readable by anyone
  • ✓ Restricted collections scoped by club
  • ✓ Users can only update their own name
  • ✓ Admins can update roles and clubs
  • ✓ First-admin bootstrap marker
  • ✓ Role checks on every restricted read

Storage & Privacy

  • ✓ Submission photos under user uid folder
  • ✓ Guest submissions under guest/ folder
  • ✓ Image type validation (client-side)
  • ✓ File size limits (8 MB photos)
  • ✓ Student data never exposed publicly
  • ✓ Passwords handled by Firebase Auth
